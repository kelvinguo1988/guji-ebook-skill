# 古逸本全册逐叶锚定战役（B 版全书重建前置）

## 方法（已验证）
1. 墨迹投影测列：`np` 对扫描页灰度投影取列带；右半叶 x∈[0.60,1.0]、左半叶 x∈[0,0.44]，
   y 取版框内 12%–88%；带宽 ≥14px。
2. 首列 = 该半叶**最右正文列带**（剔除贴边缘版心条：右半 b[0]≥0.975、左半 b[1]≤0.025 的带；
   TODO：框线竖线会并入边缘带，需加宽度≥22px 且墨密度过滤——grid3 版即败于此）。
3. 网格拼图：每页上下两格（右/左半叶首列+次列），10 页一张，人工读首列起 2–6 字。
4. 锚映射规则：叶首=经文 → 该字位（可跨叶断词）；叶首=注文（首或尾）→ 其所属经句句末之后的下一经文字位
   （注不占流位，注跨叶由排版自然溢出承接，记结构性容差）。
5. 全部锚必须严格递增；跨度断言（verify_leaf_spans）随构建强制。
